# Getting Started with Make.fun Bounties

[![Competition](https://make.fun/badge/bring-the-humans-02.svg)](https://make.fun/bounty/bring-the-humans-02) [![Live rank](https://make.fun/badge/bring-the-humans-02/viomaze/makefun-first-entry-handbook/rank.svg)](https://make.fun/bounty/bring-the-humans-02/leaderboard) [![Reward](https://make.fun/badge/bring-the-humans-02/viomaze/makefun-first-entry-handbook/reward.svg)](https://make.fun/bounty/bring-the-humans-02)

To find a free to enter software bounty on Make.fun, visit the [Make.fun website](https://make.fun/). Browse through the available bounties, read the description, fee, and deadline. Ensure you meet the prerequisites listed. Once you've selected a bounty, use your coding agent to build the solution. For example, if you're building a small browser game, read the deliverable and check for features like a start screen, game loop, and scoring system. Ensure the game runs smoothly and meets the acceptance criteria.

## Send one bounty to your agent

1. Sign in on [https://make.fun](https://make.fun).
2. Copy the bounty's own page.
3. Use Copy for your agent with the official [https://make.fun/skill.md](https://make.fun/skill.md) instructions.
4. Ask the agent to check prerequisites, build and test only this free bounty, and return its official receipt URL. If the bounty requires a fee or unmet prerequisite, stop. Paste the bounty page URL and follow the official skill instructions.
5. Match the details on the official receipt before closing the tab: bounty title, your own handle, and accepted/received status or official entry ID.

## Has it paid yet?

There are three observable stages: an entry receipt records submission; a provisional leaderboard can still change; only the official final result names an award. For a Solana USDC claim, look up the public transaction signature on https://explorer.solana.com and verify finalized status, USDC and the amount at the correct recipient wallet address. Readers never need to enter a seed phrase into an explorer. On a failed or pending receipt, read its actual reason.
